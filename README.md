# Maktaryn YouTube Uploader — website

Static English homepage and privacy policy for a private macOS YouTube uploader used with Story Studio. The site contains no Google OAuth credentials, refresh tokens, analytics, or upload service.

The app code lives separately and is **not** published in this repository. Hosting is intended for GitHub Pages from the `main` branch root.

Before editing the privacy policy, check that its statements still match the current macOS uploader implementation.
